Comparison Matrix

How each method addresses the five core problems of long-context transformers.

Exploding KV Cache Still stores every token individually. 90% memory reduction via dense chunking. Compresses history into fixed-size memory. Permanently drops oldest tokens. Shortens prompt before LLM.
Quadratic Compute Still compares every word to every past word. Lightning Indexer skips irrelevant history. Checks fixed memory, not growing list. Fixed window caps comparisons. Reduces input length.
Immediate Context Loss No compression; exact wording preserved. Sliding window keeps recent words exact. Local masked attention preserves precision. Sliding window preserves recent context. Compression risks stripping nuances.
Long-Term Amnesia All data retained in KV cache. Nothing permanently deleted; HCA retains summaries. Distant details blur in compressed state. Evicted tokens permanently forgotten. Deleted sentences cannot be recalled.
Lost in the Middle Rescaling prevents attention decay mid-document. Synthesizing buried facts still degrades accuracy. Compression blurs exact details. Only remembers beginning sinks + recent end. Less raw data to connect the dots.

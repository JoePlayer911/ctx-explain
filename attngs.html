Attention-Guided Prompt Compression — "Attention-Guided Context Compression for Efficient Personalized LLMs"

Unlike other methods that modify the transformer's internal attention, Attn-GS operates before the prompt reaches the LLM. A marking model analyzes attention patterns to score each sentence's importance, then a compression model strips low-value content — achieving up to 50× token reduction while preserving task-critical information.

Method Properties

✅
KV Cache: Shortens the prompt before it reaches the LLM — fewer tokens to cache.
✅
Quadratic Scaling: Reduces input length, directly reducing attention computation.
❌
Immediate Context: Coarse compression risks accidentally stripping subtle prompt nuances.
❌
Long-Term Amnesia: Physically deleted sentences cannot be recalled later — irreversible loss.
❌
Lost in Middle: Stripping tokens upfront gives the model even less raw data to connect the dots.

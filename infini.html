⚠ Memory Interference — The Fundamental Trade-off

You might ask: how does the model know that a value in the matrix is about past vs. new information?

The answer is: it doesn't perfectly distinguish them. The memory matrix stores Key→Value associations via M += σ(K)ᵀV. If a new fact produces a Key vector similar to a past fact's Key, the new Value blends into the old one — they physically overlap in the same matrix cells.

Segment 2 arrives:
Key("pet") → Value: "User has a dog" ⟹ stored in M at cells governed by Key("pet")
Segment 5 arrives (similar topic!):
Key("pet") → Value: "User has a brown-eyed chihuahua"
⟹ Since Key("pet") ≈ Key("pet"), the new value BLENDS INTO the same cells
⟹ Retrieved value becomes: "User has a ??? dog/chihuahua" (blurred)
The model has hundreds of dimensions to minimize collisions, but with enough context, interference is inevitable. This is exactly why Infini-attention suffers from Long-Term Amnesia and Lost-in-the-Middle — it cannot perfectly recall highly specific, colliding facts.
Learned Gating — Information Blend Ratio
Local A_dot · (1−σ(β))Memory A_mem · σ(β)
Gating β acts as a learned balancing switch. A high β (closer to 1.0) forces the attention layer to retrieve facts from the global compressive memory (historical text), while a low β (closer to 0.0) limits focus to the local attention window (immediate active words).
